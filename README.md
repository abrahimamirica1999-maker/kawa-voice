Review sheet. Static page, no build step; GitHub Pages serves it.

Now (2026-10-24): **fix all typos**. Every row of the Corrections sheet of the owner's typo workbook
(`typo-review-all-courses-2026-10-21.xlsx`, 499 texts from all three courses), one per screen, in two groups picked
on the first screen:

- **Arabic + English** (265): Fusha (in the Kurdish courses), Iraqi Arabic, English. Screens in Arabic.
- **Kurdish** (234): Standard Kurdish (Sorani), Hawleri. Screens in Sorani.

Each screen says what the text must be written in, the English meaning from the course (for a single word of an
arrange exercise also the sentence it belongs to), the text now, the suggested fix and why (English). The reviewer
answers "suggestion is right" / "text is right, keep it" / types the right text, plus an optional note. Paging past
records nothing. The workbook's Wrong letters sheet is not here (fixed automatically).

`items.json` is generated by `build_items.py` (run from the app repo's `others/kawa-voice`). Ids are
`x` + sha1(lang|text)[:8]; `r` is the workbook row (#).

Answers go to the Google Sheet **"fix all typos"** through `apps-script.gs` (bound to it, web app, execute as me,
access **Anyone**; its `/exec` URL is `SHEET_URL` in `index.html`; change the script with Manage deployments → edit →
new version so the URL stays). Tabs: `answers` (one row per text, upserted on item_id: decision, correct_text,
changed, note) and `log` (every post, raw).
