Hawleri answer sheet. Static page, no build step; GitHub Pages serves it.

Now: the Standard Kurdish flashcard words, one per screen by category, for the
native speaker to turn into Hawleri. `items.json` is generated by
`build_items.py` (run from the app repo's `others/kawa-voice`). Words she
already converted in the hawleri-tests round arrive pre-filled with her answer
for her to confirm.

Answers go to the "Kawa answers" sheet, one batch per category
(`flashcards:00` ... `flashcards:38`). The earlier Kawa conversation batches
(batch-1 to batch-4) are in this repo's history.
